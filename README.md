# Student Management System

## Features

- CRUD Operations
- Spring Security
- JWT Authentication
- Validation
- Pagination
- Sorting
- Search by Name
- Swagger Documentation
- DTO Pattern
- MySQL Integration

## Tech Stack

- Java 17
- Spring Boot 3
- MySQL
- Spring Data JPA
- Spring Security
- JWT
- Swagger

## Run Project

1. Configure application.properties
2. Create MySQL database
3. Run:

mvn spring-boot:run
